# 架构决策记录

每篇记录说明当时要解决的问题、采用的方案，以及这个选择给实现带来的约束。

| 设计问题                                     | 已采用的决策                                                                                                               |
| -------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 服务端首屏和浏览器交互如何放进同一个应用？   | [0001 应用与工程基线](0001-application-baseline.md)采用 App Router 组织页面与 HTTP 入口，按业务功能组织实现。              |
| 两个入口读取同一份目录，哪些结果适合复用？   | [0002 公开读取与缓存](0002-public-reads-and-cache.md)让页面与 JSON 接口共用读取器，并分别约束 HTTP 缓存和服务端缓存。      |
| 页面同时用到目录和结算时，代码放在哪里？     | [0003 前端模块组合](0003-frontend-module-composition.md)由页面通过公开入口组合两个 feature，各模块独立维护业务规则与视图。 |
| 旧报价成交时，怎样保留用户后来修改的购物车？ | [0004 Java 集成结算](0004-java-integrated-checkout.md)将草稿与交易分开保存，按报价时记录的行版本清理购物车。               |

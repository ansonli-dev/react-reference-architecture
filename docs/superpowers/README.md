## 执行顺序

| 指导书阶段 | 可直接执行的计划                                              | 依赖                                                | 可验收产物                                              |
| ---------- | ------------------------------------------------------------- | --------------------------------------------------- | ------------------------------------------------------- |
| P0/P1      | [01 基线与契约](plans/2026-11-17-01-foundation.md)            | 现有 `main`                                         | 双语 shell、demo/release 分离、契约与质量门禁           |
| P2         | [02 目录](plans/2026-11-17-02-catalog.md)                     | A1–A5                                               | 可直接打开的目录、详情及 SSR/缓存证明，Java v1 只读适配 |
| P3         | [03 会话、购物车与结算](plans/2026-11-17-03-checkout.md)      | P2                                                  | 教学版身份、草稿、报价、提交和重试                      |
| P4         | [04 订单和管理](plans/2026-11-17-04-orders-and-management.md) | P3                                                  | 四条流程完整教学版，以及授权、并发和缓存测试            |
| P5 Java    | [05 Java v2 与联调](plans/2026-11-17-05-java-integrated.md)   | J1–J6 可先做。J7 等 D4 与 Java 契约。J8 等 J7 与 E1 | 真实身份及目录、交易、取消、管理端到端                  |
| P5 交付    | [06 发布与运行](plans/2026-11-17-06-release.md)               | D4 启动 E1/E2，E3 分别汇总教学证据与 J8 真实证据    | 发布容器、运行与架构文档、可访问性及观测记录            |

建议第一批执行 A1–A5，再做 B1–B4，先让读者从 `/zh-CN/books` 看到可审阅的架构实例。具备 Java 开发环境后可并行验 J1→J2，随后按 J3/J4→J5→J6 接通真实流程。E4 的虚拟化和独立 NestJS 只在主线已验证后单独演示。计划的依赖与命令按各任务的前置约定执行。

## 验收线

| 验收线       | 要求                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| 本地教学版   | 四场景跑通，无需 Java/容器/外部 IdP，双账号越权、写入失败、SSR 和恢复有证据                 |
| 真实只读兼容 | 运行当前 Java catalog，真实 HTTP 核对列表/详情。未启用交易时可解释                          |
| 真实集成版   | Next、Java 和 IdP 用固定版本启动，通过四场景及规定故障用例，记录两个 commit、请求和事件结果 |

A1 先更新当前 Next.js 安全补丁。计划中的命令和断言由对应任务实现和执行。真实联调、兼容证据与本地测试分别记录。

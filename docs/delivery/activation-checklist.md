## 凭据预览

| 名称                               | 范围                                                               |
| ---------------------------------- | ------------------------------------------------------------------ |
| `RRA_KUBECONFIG`                   | 各 environment 的短期最小 deployer 身份                            |
| `RRA_TEST_CONTROL_KUBECONFIG`      | test coordinator 的单个控制记录 CAS；核对 `rra-test` UID           |
| `RRA_TEST_LOCK_READ_KUBECONFIG`    | 单对象只读，供 test/prod 工作负载核对协调意图                      |
| `RRA_REGISTRY_USER/PASSWORD`       | 指定制品仓库 push；节点拉取凭据由配置者另行维护                    |
| `RRA_PROMOTION_APP_ID/PRIVATE_KEY` | 仅指定仓库的 Contents/PR 写和 Actions 读，经证实的 test 协调器使用 |
| `RRA_GITHUB_READ_TOKEN`            | 只读 GitHub run/attempt、job 与 provenance artifact                |
| `RRA_MULTICA_CALLBACK_URL`         | 已验证平台接收入口，保存为秘密                                     |

无需把现有个人 token 或 kubeconfig 内容交给审查者。单独批准执行版本前，保留所有 workflow job 的固定禁用条件；CI 检查继续由 GitHub-hosted runner 执行。
